# 日志收集与打包下载

日志收集用于把主机上的日志文件下载到本系统并生成 ZIP，支持微服务、数据库、RabbitMQ、Redis 及其他日志。在线检索和持续查看继续使用 VictoriaLogs。

## 使用流程

1. 在“服务器管理”中配置日志所在主机的 SSH 连接，连接账号需要能读取对应目录和文件。
2. 打开“日志收集 → 日志来源”，新增来源：类型、名称、主机、绝对目录、文件名匹配规则，以及是否包含子目录。
3. 勾选一个或多个来源，点击“选择日志文件”。页面展示各来源的文件列表，读取失败的来源显示具体主机、目录和错误。
4. 按文件路径或文件修改时间筛选，勾选文件后点击“开始收集并打包”。
5. 在“收集记录”中查看逐文件进度、读取大小和错误，完成后下载 ZIP。记录及收集包可手动删除，原始日志不受影响。

来源示例（目录以实际部署为准，不会自动创建这些配置）：

| 类型 | 名称 | 主机 | 目录 | 文件规则 |
|---|---|---|---|---|
| 微服务 | 计费服务 | 业务节点 A | `/data/logs/billing` | `*.log,*.log.*,*.gz` |
| 数据库 | PostgreSQL 主库 | 数据库节点 A | `/data/postgresql/log` | `*.log,*.csv,*.json,*.gz` |
| RabbitMQ | RabbitMQ | 消息节点 A | `/var/log/rabbitmq` | `*.log,*.log.*,*.gz` |
| Redis | Redis | 缓存节点 A | `/var/log/redis` | `*.log,*.log.*,*.gz` |

同一个服务分布在多台主机时，每台主机配置一个来源，然后一起选择收集。名称用于标识实际服务或组件，不要求绑定应用管理中的构建应用。

## 收集规则

- 文件规则按文件名匹配，多个规则用逗号或换行分隔，`*` 表示全部普通文件。递归扫描可选，扫描不跟随软链接。
- 时间筛选使用文件的修改时间，下载的是整个文件，不解析或裁剪日志内容中的时间段。
- 正在写入的文件按开始读取时的大小收集；之后追加的内容需要再次收集。正在收集的文件若缩短，按读取不完整记录失败。
- 文件先通过 SFTP 写入本地临时文件，完整读取后才加入 ZIP，失败文件不会以截断内容进入压缩包。
- 各文件按顺序处理。一个文件或主机失败后继续其他文件，结果明确区分全部成功、部分成功、失败、已停止。
- 停止操作会中断远程读取；已经进入本地压缩的文件完成后结束，保留此前成功收集的文件。未完成文件在清单中标明。
- ZIP 按“类型 / 主机及编号 / 来源及编号 / 原相对路径”组织。同名文件不会跨来源覆盖。
- ZIP 内附 `collection-manifest.json`，记录来源快照、主机、原路径、文件大小、实际读取字节数、修改时间和结果，不包含主机密码或私钥。全部失败时生成的 ZIP 只有收集清单。

## 保存与下载

日志来源和收集记录保存在 PostgreSQL 的 `log_sources`、`log_collection_jobs` 表中，程序启动时自动建表。ZIP 保存在 `<workspace.base_dir>/log-collections/<任务编号>/logs.zip`，目录须可写且有足够磁盘空间；每个任务会额外暂存当前正在读取的一个文件。

下载采用带身份验证的表单 POST，由浏览器处理 ZIP 下载，不将整个压缩包读入页面内存，登录凭据不写入下载 URL。保存的文件包不会自动过期，可在收集记录中手动删除。

后端重启时，未完成任务标记为失败并清理未完成的收集包，提示重新收集；已完成记录和 ZIP 可继续下载。本系统磁盘写入、ZIP 制作或进度保存失败会中止任务，不会把不完整压缩包发布为完成。

每个来源预览最多返回 5000 个匹配文件，遍历最多 20000 个目录条目、32 层子目录；超过时明确报错并要求缩小来源范围，不静默截断。单次任务最多选择 5000 个文件。每次 SFTP 目录操作或文件分块读取超时为 60 秒，本地压缩期间不计入网络超时。

## 接口

接口前缀：`/api/log-collection`。

| 方法 | 路径 | 功能 |
|---|---|---|
| GET / POST | `/sources` | 查询 / 新增来源 |
| PUT / DELETE | `/sources/:id` | 编辑 / 删除来源 |
| GET | `/sources/:id/files` | 预览匹配文件 |
| GET / POST | `/jobs` | 分页查询 / 创建收集任务 |
| GET / DELETE | `/jobs/:id` | 查看详情 / 删除任务和收集包 |
| POST | `/jobs/:id/cancel` | 请求停止 |
| POST | `/jobs/:id/download` | 原生浏览器下载，表单中提交 `token` |

创建任务的参数示例：

```json
{
  "selections": [
    { "sourceId": 1, "files": ["current.log", "archive/2026-09-10.log.gz"] },
    { "sourceId": 2, "files": ["rabbit.log"] }
  ]
}
```
