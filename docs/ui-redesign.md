# CloudHIS 控制台 UI 重构

本次调整公共布局及组件样式，并重构工作台、日志收集和登录页。其他业务页面复用统一的按钮、表格、表单、弹窗和主题样式，原有业务操作保持可用。

## 视觉规范

- 浅色为主：灰蓝底色、白色内容区、深蓝标题、电蓝主操作和青色细节。
- 统一侧栏分区、面包屑、页签和键盘焦点；窗口较窄时初始折叠导航。
- 内容区使用统一间距、细边框、圆角和轻阴影；表格维持适合运维数据的密度。
- 深色主题采用蓝灰色层级，保留成功、失败、警告的独立颜色。
- 概览数字来自实际接口或当前来源配置，不为视觉效果生成生产统计。截图使用模拟接口数据。

## 页面调整

- 日志收集：来源 / 主机 / 类型概览、来源图标、文件路径字体和分层表格；收集、停止、下载及历史流程保持原有行为。
- 工作台：使用后端 `todayBuilds` 字段显示今日构建，移除写死的增长数字和无数据时的 67% 成功率；快捷入口指向已存在的页面。
- 登录页：调整双栏布局，移除虚构的应用数、构建量和成功率，手机宽度保留完整登录表单。
