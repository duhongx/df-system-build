# 前端逐页审核（2026-10-14）

范围为全部 30 个页面组件、37 个有实际组件的路由页面，以及公共布局、个人资料弹窗、组件语言和相关接口。审核结合 150 的真实页面、源码和独立临时数据库验证。未把缺少真实业务数据的状态当作已经实测。

## 主要问题与处理

| 问题 | 影响 | 处理 |
|---|---|---|
| 历史“删除”调用取消 API | 可把完成历史改成已取消，记录并未删除 | 改为仅活动任务可取消；后端条件更新保护 SUCCESS／FAILED／CANCELED 终态 |
| 历史搜索／类型只筛当前页 | 漏查记录、分页总数不符 | 后端先筛选再计数、分页，改变筛选返回第一页 |
| 最新制品库取最多 500 条再筛选 | 最新制品可能漏查，分页不真实 | 后端 latest 条件及真实总数分页 |
| 多个列表固定高度或随行数收缩 | 小窗口超屏，大窗口浪费空间 | 10 个列表和 5 个 K8s 资源列表填满内容区，表内滚动 |
| 服务器按钮截断、K8s 操作列远离视口 | 常用操作不可见 | 按钮换行、K8s 操作列固定右侧 |
| 长失败诊断占满详情页面 | 阶段和日志被挤到屏幕下方 | 首段摘要＋折叠完整诊断，保留全文并限制展开高度 |
| 终端高度及重连事件清理不正确 | 底部溢出，重连可能累积粘贴／缩放事件 | 内容区 flex 布局、ResizeObserver、统一释放旧连接和监听器 |
| 详情路由同组件复用 | 切换 ID／查询参数可能继续展示上一个对象 | 子路由按完整路径重建，公共导航保留 |
| 没有中文组件语言 | 分页、空数据等仍英文 | 全局中文 Element Plus 配置 |
| 大弹窗缺少视口限制 | 小窗口无法访问完整表单和底部按钮 | 全局限宽／限高，正文内部滚动，保留底部按钮 |
| 固定多列与工具栏不换行 | 窄窗口挤压和截断 | 标题／操作／工具栏换行，概览与监控网格随宽度降列 |
| 深色模式部分白底、深色标题 | 显示割裂、文字难读 | 补充业务卡片、标题、代码区和 SQL 选择态主题色 |
| 构建后清理开关没有实现 | 保存后误以为源码和中间产物已清理 | 移除未生效选项，原数据库键保留 |
| 全局并发和日志范围说明不足 | 保存后以为并发立即改变或所有日志都清理 | 标明并发重启生效，清理范围为构建阶段日志 |
| 个人信息虚构默认资料、用户名可编辑但接口不保存 | 加载失败误显示测试资料、修改无效 | 空默认值，加载失败禁用保存，用户名只读，去除不存在的重复账号字段，邮箱可选 |
| 公共编译列表状态英文、默认配置未说明 | 不知道哪些配置生效及是否仍需选择 | 启用／停用中文及默认标签，说明任务自动带出 |
| OAP／GraphQL 测试范围未说明 | 以为整组地址及 GraphQL 均已测试 | 明确当前只测首个 OAP 地址，GraphQL 用于模板但未校验 |
| 返回任务队列的按钮称滚动更新 | 误以为点击即执行更新 | 改为查看任务队列 |
| 旧任务待手动更新仍称所有任务的第二步 | 与本地自动更新规则混淆 | 改为待手动滚动更新并说明本地新任务自动执行 |
| 部署参数出现真实凭据式示例、通知密钥明文 | 不合适的默认内容和明文展示 | 通用参数占位符，通知 Secret 使用密码输入框 |
| SSH 私钥称作证书；SQL 示例使用 his schema | 操作者可能填写错误字段或业务账号 | 改为 SSH 私钥／口令；SQL 示例改为 df_ 业务 schema |
| 接口没有返回 CPU／内存百分比却显示空列 | 表格似乎丢数据 | 移除无来源的百分比列，保留真实用量 |
| 监控接口失败仍标监控中 | 错误状态与状态标签矛盾 | 失败时显示监控不可用 |
| 部署运行详情回滚没有确认、加载失败缺少说明 | 易误触或看到空页面 | 回滚前确认目标范围，补加载失败提示；未执行回滚 |

## 实际环境问题

- 150 的 `node_exporter` 地址 `192.168.1.150:9100` 连接被拒绝，监控正常数据状态需启用相应服务后再验收。本轮不安装或启动额外服务。
- 已有 agg-service 发布失败记录及 Pod 未就绪属于业务运行异常。失败日志显示 RabbitMQ 连接拒绝，页面保留完整诊断；本轮不重新发布、回滚或修改业务依赖。
- 当前没有基础设施部署运行记录，部署运行详情的有效数据与回滚后状态仅做代码检查，未伪造生产记录。

- 前端生产构建和 TypeScript 检查通过；8 个现有前端测试脚本通过。更新了仍要求旧“构建与部署”文案的断言。
